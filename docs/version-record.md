## 回退规则

1. 应用版本回退使用阶段标签或 `git revert <commit>`，不使用强制推送和硬重置。
2. 数据库只允许向前兼容迁移；回退应用不能恢复已撤销 Token、凭据或云资源状态。
3. 生产发布回退只切换已验证镜像；若迁移不可逆，先进入维护模式并执行对应恢复演练。
4. 恢复环境默认 `MAINTENANCE`，订阅返回 503，worker 禁止云写，直到审计追平和凭据轮换完成。
