# 控制台视觉规范

P5 使用固定 Vben `v5.7.0` 信息架构，面向单管理员重复运维。界面采用紧凑侧栏、
白色工作面和表格优先布局，不使用营销 Hero、装饰渐变、嵌套卡片或假指标。

- 主背景 `#f5f7f9`，工作面 `#ffffff`，导航 `#182127`，强调色 `#087f8c`。
- 状态色分别使用绿色、琥珀色和红色；能力状态必须展示文字，不能只依赖颜色。
- 圆角上限 6px；控制高度 36px；表格行高 48px；页面最大宽度不设卡片外框。
- 标题 22px/600，页面正文 14px/1.5，表头和操作栏 12–13px；字距固定为 0。
- 左侧导航在桌面为 232px，窄屏收为顶部抽屉；危险操作在独立确认对话框完成。
- 图标使用 Lucide 线性图标；图标按钮必须提供可访问名称和 tooltip。
- 空状态来自真实空数据；API 失败使用显式错误带和重试按钮，不显示示例资源。
- 秘密只在一次性交付对话框的内存状态存在，关闭、超时、401 或退出立即清除。

由于当前会话没有内置图像生成工具，本规范作为代码原生概念基线；实现后以桌面和
移动浏览器截图、DOM 行为和可访问性断言进行对照验收。
